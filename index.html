🌎 UHRI UNIVERSAL - HOW TO USE - KEEPER VERSION

1. SET UP COMPANY (Once):
Tap ⚙️ Company → Name, Phone, Email, License, Inspector, State (50 states), Country (200+), Standard (TREC / ASHI / InterNACHI / Generic). Upload Logo — Shows on top + reports.

2. START INSPECTION:
Fill Client + Property + Fee. Read Pre-Inspection Agreement.
• Tap 📖 Read Full Agreement — Expand for large, easy-to-read version. Tap ⬅ Back to Agreement to go back, or 📋 Return to Report to skip to inspection.
• Tap Later to skip agreement for now, or ✅ SIGN & START to sign (type name + date).

3. FILL EACH AREA — 20 Sections:
Tap a section — e.g. 1. EXTERIOR - ROOF — Fill each item:
• I/NI/NP/D: I = Inspected, NI = Not Inspected, NP = Not Present, D = Deficient
• Type ↓: If you see Type — Pick type. Example: Water Heater → Gas / Electric / Tank / Tankless. HVAC → Central / Heat Pump / Furnace / Mini Split / Ductless Mini Split. Roof → Composition Shingle / Tile / Metal / Flat.
• Condition ↓: Pick condition. Example: Appeared in good condition, Appeared to operate normally, Appeared in fair / poor condition, Deficient, Needs Repair, Safety Issue, Monitor.
• Value: Type size / number / measurement. Example: Main Breaker Size → 200 Amp. Number of Breakers → 24.
• Windows: Pick Type — Double Hung / Single Hung / Sliding / Fixed / Casement / Awning / Picture — Then in Value type How many windows? — e.g. 3.
• 📷 Photo: Take / pick photo for that item.
• Comment: Type notes.
• Everything auto-saves as you type.

4. NEXT BUTTON — Go to next area:
At the bottom of each area, tap Next → Next Area ➡️ — Saves this area and opens the next one. Tap ⬅ Prev to go back one area. On last area, Next becomes ✅ Done — Back to All Sections.

5. ELECTRICAL — PANELS:
• Main Disconnect - Main Breaker Size: Type main breaker size — e.g. 200 Amp.
• Main Panel - Number of Breakers: Type how many breakers total.
• Main Panel - Breaker Count Table: Type how many of each size — 15 Amp, 20 Amp, 30 Amp, 40 Amp, 50 Amp, 60 Amp, 100 Amp. Total updates automatically.
• Sub Panel(s) - Breaker Count Table: Same for sub panel(s) — 15 Amp to 60 Amp.

6. SAVE / PREVIEW / SEND:
• Tap 💾 SAVE top right — Shows SAVED! popup.
• Tap ↗ Preview — Shows report inside app.
• In Preview → 📧 Email Report to open Mail, or 🖨️ Print / PDF to print / Save as PDF.

7. TIPS:
• Tap ➕ ADD ITEM to add your own item to any area.
• If you skip agreement, tap 📋 Agreement Signed/Skipped bar at bottom to bring it back.
• Section 2 Exterior Walls / Trim has no Doors / Windows — Doors / Windows are in their own rooms / Garage / Interior sections.
